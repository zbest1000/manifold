# UI Backlog

Running list of UI/UX issues discovered during the overhaul, with evidence and
proposed fixes. Ordered roughly by impact. Checked items are done; the commit or
PR that closed them is noted inline.

## Open

Re-checked against the code in November 2026, after the redesign (design system, every
page rebuilt, the mapping editor, canvas rendering, the Playwright suite).

### Medium

- [ ] **Sparkplug primary-host control sits on the Tags page**
  (`pages/tags/HostStatePanel.jsx`, a collapsed panel beside the mappings of a source);
  it belongs on the broker.
- [ ] **A connections hub.** The design (`docs/design/southbound-drivers.md`, section 8)
  lists MQTT and OPC UA connections next to devices under one "Add" picker; today they are
  separate pages. Device nodes do not appear in the UNS topology either.
- [ ] **Mapping preview has no lint delta**, only collisions, raw-address and option
  warnings.
- [ ] **Promote the locally built primitives** (side panel and floating bar chrome, editor
  parts, descriptor forms, the list-tab helpers) into `components/ui`; the candidate list with
  file paths is in the design system, section 13.

### Low

- [ ] **Sorting is partial.** Brokers, OPC UA connections, Discovery results, Devices, Pipelines
  routes, mappings and the live tag table sort; the Historians, Recorder, Models and Contracts
  lists do not.
- [ ] **One bare `.catch(() => {})`** remains in `pages/OpcUa.jsx` (the list re-read after a
  failed connect, whose error the form already shows).
- [ ] **Main-chunk size was not re-measured** after the redesign (every page is a lazy chunk).
- [ ] **Defects seen while capturing the documentation screenshots** (details and reproduction
  in `docs/REVIEW-2026-11.md`, "New findings from the screenshot pass"): a very large float
  overflows its cell in the device drawer's Tags tab (S1, open); S2 to S5 are fixed. The second pass
  (all images regenerated by `npm run docs:shots`) found: the reopened OPC UA mapping showed
  "from server" over empty fields (S6, fixed); at 1440 px the Overview's Connections table and the
  Pipelines Routes table scroll horizontally, cutting off the State column and the row actions (S7, fixed);
  a reopened OPC UA mapping's tag table leaves Unit and Description blank (the details panel has them) (S8).
- [ ] **Verification gaps:** WebGL and 3D were only run on a software renderer; no screen-reader
  or manual keyboard audit beyond what the specs drive.

## Done (recent)

- [x] **Concurrent edits** (Nov 2026): every stored object has a `rev`; a stale save is refused
  with `409 stale` and the conflict dialog (Keep mine / Take theirs / Cancel) on devices, profiles,
  brokers, routes, models, historians, recordings, contracts, alert rules, mappings and OPC UA
  connections. Mappings and OPC UA connections are tested with two real browser contexts.
- [x] **Payload field order** is editable in the mapping editor (buttons and keyboard).
- [x] **MQTT-topic selections create mappings** (with a reviewed migration of old routes).
- [x] **Tailwind compatibility layer retired**: no legacy class names left; a unit test guards it.
- [x] **Overview "Needs attention"** lists rejected or growing historian backlogs, firing alerts,
  mappings that do not publish and broken references, each linking to the fix.

- [x] **The redesign (Nov 2026).** One design system (`docs/design/ui-design-system.md`):
  semantic tokens, light, dark and system themes, IBM Plex, primitives in `components/ui`. Every
  page was rebuilt on it: Overview, MQTT Brokers, Devices (sortable table, detail drawer, full-page
  form, Profiles, bulk create, Discovery), Tags (a two-tab workspace and the single-sheet **mapping
  editor** that replaced the three-step wizard), Pipelines (five tabs, route editor with dry run and
  the TVQ hint), OPC UA, CESMII SMIP, i3X, Settings (Session card, theme, topic graph, alert rules,
  configuration, audit trail), the unlock screen and the icon picker.
- [x] **Canvas rendering overhaul.** `graph/canvasKit.js` (DPR-correct sizing, one camera transform
  for drawing and picking, a frame scheduler that is idle at about 1 frame per second and stops when hidden,
  label level of detail, WebGL context-loss recovery), canvas themes derived from tokens in both themes,
  a validated data palette, deep links `/uns?broker=&path=` and `/topics?broker=&topic=` with a jump state
  machine, graph styles Standard, Schematic and Monochrome.
- [x] **Read-only UX.** Disabled controls with the reason, `ReadOnlyNote`, the Session card with **Sign out /
  use a different token**.
- [x] **Test and CI.** Playwright projects desktop, hidpi and mobile with axe in both themes,
  functional specs for devices, profiles, outage, mapping, pipelines, settings, auth and OPC UA;
  ESLint for client, server and mcp in CI.
- [x] **Deep link from a mapping to its node in the UNS** (**Show in UNS**) and the **Advanced**
  section of the device form (Modbus unmapped ranges, process isolation).
- [x] **UNS topology over-zooms when a deep mount is present**, and **OPC-UA / i3X mounts default
  fully expanded**: auto-fit frames only broker trees (`fitTransform` in `graph/unsLayout.js`) and
  `seedExpansion` seeds mounts collapsed.
- [x] **Modal portal consistency.** Every overlay uses the shared portaled `Modal`, `Dialog` or
  `Drawer` (`components/ui/overlay.jsx`); no `fixed inset-0` overlay exists outside `components/ui/`
  (searched Nov 2026).
- [x] System "Process health" sparklines blank after a restart (dashed baseline until the second
  sample), replay scrubber polish (keyboard slider, time labels, ticks), density and spacing audit tail.

- [x] A shared Y axis flattened mixed-magnitude tags (temperature ~50 went flat
  next to speed ~1450). Added a Normalize toggle to Trends that rescales each
  series to its own 0-100% range so shapes compare directly; the legend keeps
  the real min-max. (`components/TrendChart.jsx`.)
- [x] Trends read empty out of the box and, worse, a file recording of the demo
  charted nothing because `recorder.series()` did `Number(objectPayload)` = NaN.
  Fixed the numeric extraction (handles `{value,unit}`), added a searchable
  captured-tags endpoint, seeded an always-on "Built-in historian" recording
  (`factory/#`), and defaulted Trends to it. Trends now has real persisted
  history on first load, no external DB. (Chose the existing JSONL recorder over
  a new SQLite native dep.)
- [x] Small object graphs (e.g. the i3X hierarchy) collapsed onto one horizontal
  line. Root cause: `treePositions` read `link.source/target` after d3's
  forceLink had mutated them from id strings to node objects, so every node
  looked parentless. Made it endpoint-agnostic and widened the tree gaps; small
  graphs now render as proper trees.
- [x] Right-click to open node properties was unreliable (OS/browser swallows the
  contextmenu). Replaced with a discoverable Properties button in the shared
  GraphToolbar and 3D controls (Topics, i3X, everywhere), tracking panelOpen so
  closing the panel no longer loses access. Extracted a shared GraphLegend used
  across views.
- [x] i3X and CESMII SMIP pages had no server to talk to locally, so they read as
  dead. Added two Docker mock servers (`docker/i3x-mock`, `docker/cesmii-mock`)
  wired into the demo compose stack; verified end-to-end (connect, catalog,
  hierarchy graph, and history chart all render live).
- [x] 3D graph had no look-and-feel controls or Beautify (2D had Beautify but 3D
  didn't). Added a 3D control cluster: Beautify (depth-graded colour ramp from the
  active palette + additive link glow + slow auto-rotate), an Auto-rotate toggle,
  and node-size / link-opacity sliders. Ref-driven so the on-demand render loop
  stays alive during rotation.
- [x] Right-clicking a graph node did nothing (browser context menu) — properties
  panel only opened on left-click. Wired `contextmenu` in all three renderers (2D
  canvas, 3D three.js, WebGL) to open the properties panel; also fixed WebGL
  click-vs-drag threshold to be HiDPI-aware.
- [x] No colour legend on the Topic graph, so group colours were unexplained.
  Added a collapsible legend (Broker / Branch / Data / Sparkplug…) to the 2D and
  3D views.
- [x] Destructive deletes (route, model, historian, recording, contract) fired
  with no confirmation. Wrapped all five in a confirm, warning about credential
  loss / data loss where relevant.
- [x] UNS "Mounts" panel only listed OPC UA / i3X, so MQTT and Sparkplug looked
  like they weren't UNS sources. Reworked into a "UNS sources" panel that shows
  Live sources (MQTT brokers, Sparkplug decoded within them) alongside Mounted
  sources (OPC UA, i3X), and explains how they connect (one namespace; bridge
  values with a Pipeline route or Tag binding).
- [x] Expanded in-app help with concrete examples and plainer wording (no
  em-dashes, no filler): richer Pipelines help; added help to UNS topology,
  Trends, and UNS sources; tightened Tags help.


- [x] Charts flashing / resetting every data tick — memoize uPlot options on a
  structural key so live data flows through `setData` (PR #43).
- [x] Health-metric popup see-through / trapped under cards — `createPortal`
  to `document.body` (PR #43).
- [x] Every chart migrated to uPlot (mature, lightweight; Grafana's engine),
  Recharts removed (~300KB off the bundle) (PR #42).
- [x] Health tiles → click to expand a full time chart (PR #42).
- [x] UNS moved nodes fighting their position — absolute pinning (PR #42).
- [x] UNS didn't center on load; lint findings now jump-to-node + explain (#41).
- [x] Sparklines rendered as filled blocks — domain padding + flat baseline (#41).
- [x] UNS multi-select + group move; Topics detail pane expandable (#41).

## How this list is maintained

Appended to during the UI-overhaul loop: each pass inspects a surface (live via
Chrome DevTools and/or by reading its component), records concrete,
evidence-backed issues here, and fixes the highest-value safe ones. Keep entries
specific — name the file, the symptom, and the proposed fix.
